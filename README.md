# Password Generator

**Автор:** Филиппов Михаил
**Версия:** 1.0

## Описание

Графическое приложение для генерации случайных паролей с возможностью настройки длины и используемых символов (цифры, буквы, спецсимволы). Все сгенерированные пароли сохраняются в историю (JSON-файл), которую можно просматривать, очищать и копировать пароли в буфер обмена.

Приложение написано на Python с использованием стандартных библиотек: `tkinter` (GUI), `random`, `json`, `datetime`.

## Функциональные возможности

- Настройка длины пароля от 4 до 32 символов (ползунок).
- Выбор типов символов: цифры, буквы (верхний и нижний регистр), специальные символы.
- Генерация пароля с проверкой – хотя бы один тип должен быть выбран.
- Кнопка копирования сгенерированного пароля в буфер обмена.
- Таблица истории с датой и временем генерации каждого пароля.
- Сохранение истории в `history.json` при каждом добавлении или закрытии приложения.
- Загрузка истории при старте.
- Очистка всей истории с подтверждением.

## Установка и запуск

1. Убедитесь, что установлен Python версии 3.6 или выше.
2. Склонируйте репозиторий: https://github.com/cojg-1/Password-Generator.git
3. Запустите приложение (password_generator.py).
